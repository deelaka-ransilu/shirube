NEVER run `pkill -f "[d]ev.mjs"` in the same tool call as other commands (it killed the shell and returned nothing); run it in a SEPARATE call or skip it. Restarting resets the in-memory db.
- Playwright: attribute selectors need quotes when the value starts with a digit; clicks that trigger async redraws need a short `wait_for_timeout`; `pg.fill` on a date input fires `input`; `pg.select_option('#id', 'value')`; `pg.expect_download()` works for the Word link; `pg.keyboard.type` types into the focused box; `pg.mouse.click(x, y)` for a backdrop click. A native `min` attribute blocks form submit before the app sees it. `pg.evaluate("window.print=()=>{...}")` with a function-expression string is CALLED once: wrap it as a statement. For the PDF: call `startPrint(cv)` through `import('/js/lib/print-cv.js')`, then `pg.pdf(path=..., format='A4')`, then `pdftotext -layout` and `pdftoppm -png`. Checks used: `#page` `scrollHeight - clientHeight` should be 0 on one-screen pages; `scrollWidth - clientWidth` should be 0; `.dock` `getBoundingClientRect().top` vs the bottom of the lowest card or list row. `pg.once('dialog', lambda d: d.accept())` before anything that uses `confirm()`.
